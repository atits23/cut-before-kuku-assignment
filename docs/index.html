THE WORKFLOW

From script to a usable cut.

Simple rules handle timing. AI reviews the story. An editor makes the final call after watching the footage.

01 / FIND

Scan the full script pack

Read every uploaded episode and find 20–60 second windows. Keep exact source timestamps and avoid cutting through a spoken line.

02 / REVIEW

Ask what stays unresolved

Your selected model checks the first three seconds, the ending and whether a new viewer can follow the scene. The API reviews your uploaded script.

03 / CHECK

Give the editor the evidence

Validate the saved review, rank the cuts and show the reason, source evidence, next beat and any concern beside each pick.

HOW TO READ THE RESULTS

Clear decisions. Honest limits.

Test first means a stronger promo idea for an initial test after checking the footage. Review further means the timing is valid, but story clarity, pacing or spoilers need attention. Thirteen episodes were not recommended.

Scores express editorial judgment, not a success probability. All 37 retained cuts pass the duration and dialogue-boundary checks. Twenty-five code tests pass, including thirteen simulated-response API tests. A live API run has not been tested. No audience performance or footage alignment has been measured.
