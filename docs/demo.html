  1. Set up: run the first cell to load the tested code.
  2. Upload: select a timestamped TXT or ZIP of episode TXT files.
  3. Connect: select Gemini or OpenAI, or configure another compatible API, and tick RUN_API. Gemini can list the models available to your key.
  4. Find promos: enter the key privately and run. Every uploaded episode is reviewed.
  5. Download: save the ranked report, CSV, JSON, model responses and validation log.
What each promo includes

Episode number · start and end timestamps · hook in the first 3 seconds · unresolved cliffhanger · why it works · rank and review concern.

Only finding the moments

20–60 second continuous segments. No video editing, music or text overlays. Confirm script timings against the footage.
